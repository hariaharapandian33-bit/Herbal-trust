# Herbal-trust

Herbal Trust is an AI-powered platform for herbal product and tablet verification. It combines barcode scanning, AI image analysis, patent and TKDL verification, GPS-based counterfeit reporting, and herbal batch recall alerts to ensure authenticity of herbal products.

## Features
- Barcode Scanning
- AI Image Analysis
- Patent and TKDL Verification
- GPS-based Fake Report
- Batch Recall Alert
